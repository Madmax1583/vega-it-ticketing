# Vega & Knitpro IT Operations Dashboard

🛠️ A comprehensive IT ticketing and NAS monitoring system built with Streamlit and Supabase.

## 📋 Features

- **Ticket Management**: Create, track, and resolve IT complaints across multiple locations
- **NAS Monitoring**: Real-time backup storage tracking with delta analysis and forecasting
- **Advanced Reporting**: Executive dashboards, SLA compliance, technician performance, department health
- **User Authentication**: Secure bcrypt-based authentication with role-based access
- **Multi-location Support**: Vega, Knitpro, and composite sector tracking
- **Excel Export**: Comprehensive multi-sheet reports with MTTR, SLA, and management insights

## 🚀 Quick Start

### Prerequisites

- Python 3.11+
- Supabase account
- Required packages (see requirements.txt)

### Installation

1. **Clone the repository**:
```bash
git clone https://github.com/Madmax1583/vega-it-ticketing.git
cd vega-it-ticketing
```

2. **Install dependencies**:
```bash
pip install -r requirements.txt
```

3. **Configure environment**:
Create .streamlit/secrets.toml:
```toml
[supabase]
url = "https://vuwxmvyzpxqhcuboqdfp.supabase.co"
key = "your-anon-key-here"
```

4. **Run the application**:
```bash
streamlit run script.py
```

## 📊 Database Schema

### Tickets Table
```sql
CREATE TABLE public.tickets (
  id INTEGER PRIMARY KEY,
  date TEXT,
  user_name TEXT,
  department TEXT,
  complaint TEXT,
  location TEXT,
  attended_by TEXT,
  status TEXT,
  category TEXT,
  start_time TEXT,
  close_time TEXT,
  resolution_time INTEGER DEFAULT 0,
  remarks TEXT DEFAULT ''
);
```

### NAS Backups Table
```sql
CREATE TABLE public.nas_backups (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  date DATE,
  server_name TEXT CHECK (server_name IN ('HRI', 'Vega', 'Sery', 'Rise')),
  status TEXT,
  storage_used NUMERIC DEFAULT 0,
  remarks TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### Users Table
```sql
CREATE TABLE public.users (
  id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  username TEXT UNIQUE,
  displayname TEXT,
  role TEXT,
  passwordhash TEXT,
  active BOOLEAN DEFAULT true,
  mustchangepassword BOOLEAN DEFAULT true,
  createdat TIMESTAMPTZ DEFAULT NOW(),
  updatedat TIMESTAMPTZ DEFAULT NOW()
);
```

## 🔒 Security

### Row Level Security (RLS)

All tables have RLS enabled with the following policies:

- **Tickets**: Full CRUD for authenticated users
- **NAS Backups**: Full CRUD for authenticated users
- **Users**: Read all, update own profile
- **Management Pack**: Full access for authenticated users

### Authentication

- Passwords hashed with bcrypt
- Session-based authentication
- Role-based access control (IT Manager, IT AM, Executive, AVP, User)

### Database Indexes
